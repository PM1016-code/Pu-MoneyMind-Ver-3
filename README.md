# PU MoneyMind Sale Page 2026

Production-ready static site for GitHub Pages. Keep `index.html`, `privacy.html`,
`terms.html`, `robots.txt`, `sitemap.xml`, and `assets/` at the repository root.

## Publish

1. Review the owner confirmation checklist below.
2. Commit the files to the `main` branch of `PM1016-code/Pu-MoneyMind-Ver-3`.
3. In GitHub: **Settings → Pages → Deploy from a branch → main / root**.
4. Open `https://pm1016-code.github.io/Pu-MoneyMind-Ver-3/` and verify every CTA.

## Owner confirmation before publishing

- Confirm `8+ years`, `1,000+ community members`, and `30+ lessons` are current.
- Confirm the Master Class promotion price and end date.
- Confirm whether GSS/TTS are included in each package.
- Confirm Live schedule, feedback scope, and Community access period.
- Confirm taxes, payment fees, exchange rate, installments, cancellation, and refund terms.
- Confirm permission to publish every review and student video.
- Add the legal entity/controller name, address, tax ID, and official contact where applicable.
- Have `terms.html` and `privacy.html` reviewed for the actual business and applicable law.

## Analytics

CTA clicks emit `line_cta_click` into `window.dataLayer` and a `pumm:cta`
browser event. Install an analytics provider only after adding the correct consent
and privacy disclosures. No tracking provider or ID is enabled by default.

## Performance

Images below the fold use lazy loading and the student video uses
`preload="metadata"`. The published Full HD student video is approximately 44 MB
and uses MP4 fast-start for progressive playback. For paid traffic, consider a
shorter teaser video while retaining the full story elsewhere on the page.
